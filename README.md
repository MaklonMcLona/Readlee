# Readlee

A responsive landing page designed for a blog-oriented web project.

## Project Overview

Readlee is a blog-oriented landing page developed to practice frontend development and responsive web design. The project focuses on a clear visual hierarchy, structured content and an accessible user interface.

The implementation uses HTML, CSS and JavaScript, with Bootstrap supporting the responsive layout. Interactive elements such as forms and popups make the page more engaging and functional.

## Project Details

- **Role:** Frontend Developer
- **Project Type:** Non-commercial
- **Category:** Landing Page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Key Features

- Responsive, mobile-first layout
- Blog-oriented content structure
- Interactive forms
- Popup elements
- Bootstrap-based layout

Improved my understanding of responsive web design, Bootstrap, semantic HTML and JavaScript interactions. Practised building structured landing pages with attention to usability and layout consistency.
